# DevOps Fundamentals Project

## Project Title

Cloud-Based Linux Server Deployment with GitHub Version Control and Automation

## Student Name

NITIN MISHRA

## Batch Code

A530

## Project Objective

To configure an AWS Ubuntu EC2 server, install the required packages, deploy a website using Apache, manage project files using Git and GitHub, and automate server monitoring tasks using Bash scripts.

## Technologies Used

* AWS EC2
* Ubuntu Linux
* Apache Web Server
* Git and GitHub
* Bash Scripting
* HTML
* Linux System Logs

## Project Tasks

1. AWS Infrastructure Setup
2. Ubuntu Server Configuration
3. Website Deployment
4. Git and GitHub Implementation
5. Bash Automation Scripts
6. Linux Log Monitoring Report
7. Project Documentation

## Bash Scripts

* health-check.sh — Checks server health information.
* apache-monitor.sh — Checks Apache service status.
* backup.sh — Creates compressed website backups.

## Log Monitoring

The `log-report.txt` file documents failed login attempts, SSH activity, system errors, and warning messages for the Linux server.
