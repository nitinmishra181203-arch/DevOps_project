# Project Documentation

## Task 1: AWS Infrastructure Setup

Created a custom VPC, public subnet, Internet Gateway, route table, security group, and Ubuntu EC2 instance on AWS.

## Task 2: Ubuntu Server Configuration

Updated the package lists and installed Git, Apache Web Server, Curl, and Vim on Ubuntu.

## Task 3: Website Deployment

Created an HTML webpage containing the project title, student name, batch code, project date, and the message "Hosted on AWS Ubuntu Server".

Deployed the webpage using Apache Web Server.

## Task 4: Git and GitHub Implementation

Created a Git repository and added the project files.

Performed Git operations including initialization, adding files, committing changes, creating a new branch, merging the branch into main, and pushing the project to GitHub.

## Conclusion

This project demonstrates basic knowledge of AWS cloud infrastructure, Ubuntu Linux administration, Apache web hosting, Bash scripting, and Git/GitHub version control.
